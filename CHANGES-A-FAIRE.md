## 🟢 Comment t'en servir

### Format pour chaque demande

Quand tu écris une demande, sois concrète :

✅ **Bon** : *« Sur la home, le titre 'Maintenant !' est trop gros sur mobile, réduis-le. »*  
✅ **Bon** : *« Sur la page Pétitions, j'aimerais que le bouton Signer soit vert au lieu de rose. »*  
✅ **Bon** : *« Ajoute un bouton 'Ma carte d'adhérent·e' dans le profil, qui ouvre une modal avec un QR code. »*

❌ **Trop vague** : *« C'est moche. »*  
❌ **Trop vague** : *« Améliore le design. »*

### Catégories d'idées suggérées par page

Pour chaque page, demande-toi :

- ✏️ **Textes** : libellés, titres, descriptions à changer
- 🎨 **Visuel** : couleurs, taille, position, photos
- 🔘 **Boutons / actions** : ajouter, supprimer, changer ce qu'ils font
- 📋 **Contenu** : ajouter / supprimer / modifier les éléments affichés
- 📱 **Responsive** : problème spécifique à mobile / tablette
- ➕ **Idée nouvelle** : feature complète à rajouter
- ❌ **À supprimer** : ce qui ne sert à rien

# ✅ AIDE-MÉMOIRE — Vocabulaire / questions fréquentes

- **« T99CP »** = la monnaie solidaire de la plateforme (1 T99CP = 1 € = 1 min de travail)
- **« Adhérent·e »** = quelqu'un qui a payé / cliqué sur Adhérer (≠ simple compte utilisateur)
- **« Commune libre »** = quartier / village / ZAD / tiers-lieu fédéré dans le mouvement
- **« Mode admin »** = bouton « Modifier » apparaît sur chaque contenu (toggle dans Tweaks)
- **« Méthode des quotas »** = en sondages, ça veut dire « pondérer les résultats selon le profil démographique des votants »
