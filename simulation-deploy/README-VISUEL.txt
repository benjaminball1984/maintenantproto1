==============================================================
SIMULATION PAGE D'ACCUEIL — pasdepesticidespournosenfants.fr
==============================================================

Cette page utilise une recréation CSS du visuel BCA en fond.
Pour avoir le rendu PHOTORÉALISTE avec votre photo réelle :

1. Renommer votre photo de hero (le visuel paysage avec l'enfant
   et le panier de légumes) en : home-hero.jpg
2. La déposer DANS CE MÊME DOSSIER, à côté de index.html
3. Recharger la page : la photo s'affiche automatiquement à la
   place du fond CSS de secours.

Format recommandé : 2400×1600 px en JPEG, ~300 Ko après compression.
